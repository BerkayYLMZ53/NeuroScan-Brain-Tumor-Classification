# NeuroScan — Streamlit Community Cloud yayını

1. Bu klasördeki dosyaları yeni bir GitHub deposunun köküne yükleyin.
2. Streamlit Community Cloud üzerinde **Create app** ile deponuzu seçin.
3. Main file path: `app.py`
4. Python 3.11 veya 3.12 seçin (dağıtım sırasında mevcut olan sürüme göre).
5. Deploy edin. Başarılı olursa çıkan URL’yi portfolyo sitenizdeki canlı demo bağlantısına ekleyin.

## Önemli
- Eğitim verisi ve notebook dağıtım için gerekli değildir.
- Yalnızca demo için gerekli iki eğitilmiş model ve CSV dosyaları bu pakette bulunur.
- Gerçek bulut kurulumu ve model tahmini bu ortamda test edilemedi; ilk deploy sonrası logları kontrol edin.
- Bu araç eğitim/araştırma amaçlıdır, klinik tanı aracı değildir.
